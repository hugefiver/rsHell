# rsHell Fluent Task21 Implementation Plan

> **For agentic workers:** Use the subagent-driven-development skill to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the approved unified Fluent dark native GTK shell, binary-embedded accessible product icons, Task20 semantic/native visual evidence, and the completed local Task21 workflow/package contract without changing product semantics.

**Architecture:** Keep the existing `rshell-ui` component and `MainWindow` message topology, and make presentation changes only in focused GTK composition, CSS, icon-registry, and smoke-evidence modules. Compile CSS and SVG sources into the binary, route every product command through the existing `MainWindow::dispatch -> command_port::dispatch -> UiCommandPort::try_send` chain, then prove the result through native GTK tests, typed visual facts, range-based rendered-image checks, and the existing PowerShell package/smoke gates.

**Tech Stack:** Rust 2024, GTK4/gtk-rs 0.10.3, Relm4 0.10.1, GIO/GdkPixbuf/GSK/Cairo from the existing GTK stack, CSS, SVG, PowerShell 7, Cargo workspace tests, GitHub Actions YAML contract inspection.

**Spec:** `docs/superpowers/specs/2026-08-24-fluent-task21-design.md`

**Global Constraints:**
- Retain GTK4/Relm4 and cross-platform architecture.
- Use one unified Windows Terminal Dark / Fluent 2 shell.
- Use a custom command bar, not a GNOME HeaderBar visual.
- Use a NavigationView-like dense sidebar, Windows Terminal tabs, a compact pane command row, and ContentDialog/settings-style overlays.
- Bundle accessible SVG icons compiled and embedded into the binary. Do not ship an external icon payload.
- Use Segoe UI as the system-first chrome face with sensible cross-platform system fallback, and use Cascadia Mono, JetBrains Mono, Consolas, then monospace for terminal content.
- Use 4px controls, 8px overlays, a 2px focus indicator, and 80 to 120ms state motion.
- Do not add fake Mica, blur, gradients, shadows, cards, or emoji.
- Preserve terminal canvas behavior and all core, session, and storage semantics.
- The only command egress remains `command_port::dispatch -> UiCommandPort::try_send`.
- Keep production modules at or below 250 pure production lines and add no UI infrastructure dependencies.
- Do not perform Git writes or install software.
- Complete UI and resources first, update native smoke and screenshot evidence second, then finalize Task21 local workflow and package contracts using embedded assets.
- Treat hosted Linux, macOS, and Windows runs as later external evidence. This work must not claim that hosted CI evidence exists.

## Interface chain

1. `theme::embedded_theme_css() -> &'static str` and authoritative `DESIGN.md` define the visual contract consumed by CSS/native tests.
2. `ProductIcon::ALL`, `ProductIcon::metadata(self) -> IconMetadata`, `ProductIcon::decode_texture(self) -> Result<gtk::gdk::Texture, IconRenderError>`, `ProductIcon::image(self) -> Result<gtk::Image, IconRenderError>`, and `ProductIcon::button(self, label_override: Option<&str>) -> Result<gtk::Button, IconRenderError>` form the only product-icon boundary; both `GtkSvg` and `InternalVector` are always compiled, and only SVG-loader-type unavailability selects the latter.
3. Sidebar, tab, pane, editor, import, and interaction widgets emit only their existing component messages; `MainWindow` remains the sole product-command gateway through `MainWindow::dispatch -> command_port::dispatch -> UiCommandPort::try_send`.
4. `collect_visual_facts(root: &gtk::Widget, requested: (i32, i32)) -> SmokeVisualFacts` inspects only approved CSS classes, allocation, visibility, and embedded-icon markers.
5. `capture_widget_png(...) -> Result<SmokeVisualEvidence, &'static str>` downloads Cairo ARGB32 bytes, calls `argb32_native_to_rgba(bytes, NativeByteOrder) -> Result<Vec<u8>, &'static str>`, then calls `analyze_rgba(...) -> Result<SmokePngEvidence, &'static str>` and writes the same GTK/GSK-rendered PNG.
6. `SmokeCounters.visual: Option<SmokeVisualEvidence>` flows through `SmokeReport`, `p0_smoke_report_visual::visual_evidence`, `P0SmokeReport.visual`, `p0_smoke_contract::assess_all`, and `scripts/qa/p0-smoke.ps1::Assert-VisualContract`.
7. `StartupProbe::report` consumes `embedded_theme_css()` and the icon registry, then `assert-package.ps1::Assert-StartupReport` proves packaged startup with binary-embedded assets and no product payload directory.

fn registry_is_closed_complete_and_binary_embedded() {
    assert_eq!(ProductIcon::ALL.len(), 16);

        .into_iter()

        .collect::<std::collections::BTreeSet<_>>();

        assert!(svg.contains("width=\"16\""));

#[test]
fn every_icon_decodes_and_snapshots_on_native_gtk() {
    gtk::init().expect("Task21 native icon test requires GTK");
    for icon in ProductIcon::ALL {
        let texture = icon.decode_texture().expect("embedded SVG must decode");
        assert_eq!((texture.width(), texture.height()), (16, 16));
        let snapshot = gtk::Snapshot::new();
        let bounds = gtk::graphene::Rect::new(0.0, 0.0, 16.0, 16.0);
        snapshot.append_texture(&texture, &bounds);
        let node = snapshot.to_node().expect("icon render node");
        let renderer = gtk::gsk::CairoRenderer::new();
        renderer.realize(None).expect("Cairo renderer");
        let rendered = renderer.render_texture(&node, Some(&bounds));
        renderer.unrealize();
        assert!(!rendered.save_to_png_bytes().is_empty());
    }
    assert!(embedded_icons_ready());
}

    -> Result<RenderedIcon, IconRenderError>

After `renderer.render_texture`, allocate `stride = width as usize * 4`, download the texture, and treat the result as Cairo ARGB32—not canonical RGBA. Cairo defines each pixel as the native-endian `0xAARRGGBB` word with premultiplied channels. Implement the conversion before any threshold logic:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum NativeByteOrder {
    Little,
    Big,
}

pub(crate) fn argb32_native_to_rgba(
    bytes: &[u8],
    order: NativeByteOrder,
) -> Result<Vec<u8>, &'static str> {
    if bytes.len() % 4 != 0 {
        return Err("argb32_length_invalid");
    }
    let mut rgba = Vec::with_capacity(bytes.len());
    for pixel in bytes.chunks_exact(4) {
        let (a, premul_r, premul_g, premul_b) = match order {
            NativeByteOrder::Little => (pixel[3], pixel[2], pixel[1], pixel[0]),
            NativeByteOrder::Big => (pixel[0], pixel[1], pixel[2], pixel[3]),
        };
        let unpremultiply = |channel: u8| -> u8 {
            match a {
                0 => 0,
                255 => channel,
                _ => (((u32::from(channel) * 255 + u32::from(a) / 2) / u32::from(a))
                    .min(255)) as u8,
            }
        };
        rgba.extend_from_slice(&[
            unpremultiply(premul_r),
            unpremultiply(premul_g),
            unpremultiply(premul_b),
            a,
        ]);
    }
    Ok(rgba)
}
```

Select `NativeByteOrder::Little` under `#[cfg(target_endian = "little")]` and `NativeByteOrder::Big` under `#[cfg(target_endian = "big")]`; do not infer byte order from the operating system. Alpha 0 canonicalizes RGB to zero, alpha 255 preserves channels, and every intermediate alpha is unpremultiplied with rounded integer arithmetic. Pass only the converted canonical RGBA buffer to threshold analysis.
